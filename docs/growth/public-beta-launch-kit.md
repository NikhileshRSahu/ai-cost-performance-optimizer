# Public Beta Growth Launch Kit

This file is the source of truth for public promotion. Never invent users,
customers, savings, logos, testimonials, security certifications, or connector
availability.

## Core positioning

**AI Efficiency Intelligence**

Find hidden AI cost and inefficient workflows, test safer alternatives against
a quality floor, and verify what actually improved.

Primary proof:
- real measured-cost public research replay
- real-world workload-pattern validation
- explicit OPPORTUNITY → TESTED → VERIFIED claim states
- public methodology and research pages

1. GitHub/public repository credibility.

3. Show HN with a technical, non-promotional explanation.
4. Relevant FinOps / AI engineering founder communities.

7. Long-tail directory and SEO distribution.
8. Targeted outbound to companies with meaningful LLM usage.

## Show HN draft

Title:
Show HN: AI Efficiency Intelligence – test LLM cost reductions before changing production

Body:
I built a tool around a problem I kept seeing in AI cost dashboards: they can
show spend, but they usually stop before answering what should actually change.

The product runs an AI Work MRI over usage evidence, turns supported findings
into bounded optimization hypotheses, benchmarks candidate changes against an
explicit quality floor, and keeps potential, tested, and verified savings
separate.

For the public beta, the calculation path is regression-tested with attributed
public measured-cost evidence and real-world LLM workload traces. Research data
is never presented as customer proof.

I would especially value feedback on:
- whether the evidence/claim boundaries are understandable,
- which optimization tests would be most useful,
- and what evidence you would be comfortable connecting first.

## Product Hunt

Name: AI Efficiency Intelligence

Tagline:
Find AI waste, test safer fixes, verify what actually saved money.

Description:
AI Efficiency Intelligence goes beyond LLM spend dashboards. It diagnoses
supported cost and workflow inefficiencies, generates bounded optimization
hypotheses, benchmarks alternatives against a quality floor, and verifies
post-change impact. Start without provider credentials and only connect deeper
evidence when useful.

Maker comment:
We built this because "your AI bill increased" is not a decision. The useful
question is: what can we change without hurting the outcome?

The product deliberately separates potential, tested, and verified savings.
Public research evidence is labeled as research evidence, and missing evidence
causes claims to be withheld rather than guessed.

## LinkedIn / X core angle

Most AI cost dashboards answer:
"Where did the money go?"

The harder question is:
"What can I safely change?"

AI Efficiency Intelligence is a public beta built around:
observe → diagnose → test → implement → verify.

No invented savings. No hidden conversion from estimates into "verified"
results.

## Rules
